Spherical O(3)
==============

These operators use ``e3nn.o3.Irreps`` and flattened ``mul_ir`` features:
``(..., mul, 2 * l + 1)`` within each entry. Linear weights are supplied
externally; biases are applied by the caller. Grid transforms instead
keep channel dimensions before the harmonic coefficient axis.
