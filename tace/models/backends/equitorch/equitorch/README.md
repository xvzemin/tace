# Equitorch

Equitorch is a package for constructing equivariant neural networks with Triton.

Author: GTML-LAB/Tong Wang

Due to several bugs in the current version of Equitorch, we temporarily copied 
and maintained a local version of the full codebase, with modifications tailored 
to the needs of TACE.
